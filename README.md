# CashTrack

CashTrack es una plataforma web para administrar cajas chicas de manera individual por usuario. Diseñada con una interfaz moderna y fácil de usar.

## Características

- **Login individual**: Cada usuario gestiona su propia caja chica.
- **Módulos completos**: Caja Inicial, Ventas, Gastos, Ajustes, Cierre Diario.
- **Control de clientes e inventario**: Con listas editables para una gestión eficiente.
- **Impresión de facturas**: Opción para imprimir facturas por cada transacción.
- **Manejo de múltiples monedas**: Visualización en dólares y colones con conversión automática.
- **Cálculos automáticos**: Caja Final = Caja Inicial + Ventas + Ajustes - Gastos.
- **Dashboard profesional**: Con gráficos de flujo de efectivo y tablas para registros diarios.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Chart.js

## Instalación

1. Clona este repositorio:
```
git clone https://github.com/Diana-NeoDuck/CashTrack.git
```

2. Abre el archivo `index.html` en tu navegador o utiliza un servidor web local.

## Uso

1. Inicia sesión con cualquier usuario y contraseña (en esta versión demo).
2. Navega entre los diferentes módulos usando el menú lateral.
3. Registra transacciones, gestiona clientes e inventario.
4. Visualiza el dashboard con información resumida.
5. Realiza el cierre diario para mantener un control preciso.
